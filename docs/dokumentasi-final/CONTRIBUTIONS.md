## Kolaborasi

Kelompok menggunakan GitHub Issues untuk pembagian pekerjaan, branch untuk pengembangan, Pull Request untuk menggabungkan perubahan, serta code review untuk memeriksa hasil pekerjaan anggota.

> Sebelum pengumpulan, pastikan nomor Issue dan Pull Request di atas sesuai dengan halaman repository dan tambahkan tautan langsung jika diminta oleh dosen. Ringkasan ini tidak menggantikan pemeriksaan detail setiap commit dan status review.
